# cinematic skill evals

Two greenfield cases for the `cinematic` skill: a 3D product story with three.js, and a scrollytelling page
where the lightest medium per scene should win over WebGL. Each run builds a site from an empty folder.

```
claude plugin eval . --eval-dir evals/cinematic --allow-tools Write,Edit,Bash --runs 2
```

These are real, billed runs; each one builds a full site.
